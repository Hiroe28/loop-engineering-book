- 工程: 初稿(/writer-draft)→指摘(/editor)→改稿(/writer-revise)。実行手順は [起動フレーズ.md](./起動フレーズ.md) のとおり

- 成果物(作品_初稿・指摘・作品_改稿)と実行記録は、このキットには収録していません(工程の顛末は書籍本文で)
