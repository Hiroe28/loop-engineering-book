# a-writer — 構成A: ライター一人の一発勝負

書籍の実験で実際に使った部屋の、実物コピーです(公開版の添え書きであるこのREADMEだけが後付け。他のファイルは実験当時のまま無改変)。

## 使い方

1. このフォルダをVS Code(またはターミナル)で開き、Claude Codeのセッションを開始する
2. `/model opus` にしてから `/writer` と打つ(詳細は [起動フレーズ.md](./起動フレーズ.md))
3. 出てきた `作品.md` を読む

## ファイルの役割

| ファイル | 役割 |
|---|---|
| [CLAUDE.md](./CLAUDE.md) | 入口の貼り紙(フェンス)。セッション開始時に自動で読み込まれる |
| [.claude/commands/writer.md](./.claude/commands/writer.md) | 起動コマンド `/writer` の中身(プロンプト) |
| [指示書.md](./指示書.md) | 仕事の手順 |
| [設定.md](./設定.md) | 物語の世界(四行の設定)。**自分の題材に差し替えるのはここ** |
| [応募要項_抽象版.md](./応募要項_抽象版.md) | 締切の条件。応募先の要項に合わせて書き換える |

## 歴史的忠実性についての注意

- 応募要項_抽象版.md の「あらすじ(100文字以内)」は、**実験当時の誤情報がそのまま走った実物**です(公式要項は200文字程度でした。誤りが発覚し訂正される顛末は書籍の第7章で)。追試するときは、あなたの応募先の要項を必ず原文で確認して書き換えてください
- 起動コマンド内の `Get-Date` はWindows(PowerShell)の日時取得です。Mac/Linuxでは `date` に読み替えてください
