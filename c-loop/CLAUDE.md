# 構成C 作業場(ライター+エディタ+オーケストレータ・3ループ)

このフォルダは実験の隔離作業場です。3つの役割は**別セッション**で動きます。

- **このフォルダの外のファイルを読まない・探さない**(上位フォルダ・隣のフォルダ・審査資料を含む)
- 渡されている資料は、このフォルダ内のファイルがすべて。情報が足りないと感じても勝手に探さず、停止して人間に確認する
- あなたがどの役割かは人間が指定する。**自分の役割の指示書だけを読む**: [ライター指示書.md](./ライター指示書.md)/[エディタ指示書.md](./エディタ指示書.md)/[オーケストレータ指示書.md](./オーケストレータ指示書.md)
- 全体の回し方は [手順.md](./手順.md)(人間向け)
