# 構成C 手順(3ループ・オーケストレータつき)※人間向け

## 準備

- `設定.md` はオーケストレータが編集してよい作業コピー。初期状態は `設定_初期.md` に保存済み(不変)
- `loops/loop1/`〜`loops/loop3/` を作る

## ループの回し方(1ループ=書く→確かめる→調整する)

各ループNで、それぞれ**新規セッション**で:

1. **ライター**: `設定.md`+`追加指示.md`(あれば)+前ループの成果を読んで執筆/改稿 → `loops/loopN/作品.md`
2. **エディタ**: 指摘 → `loops/loopN/指摘.md`
3. **オーケストレータ**: 出来栄えを判断し `設定.md`・`追加指示.md` を修正 → 記録を `loops/loopN/判断.md`

## 停止条件

- **3ループで打ち切り**(ループ3のオーケストレータ工程は「完成宣言と総括」のみ。それ以上回さない)
- 最終稿 = `loops/loop3/作品.md`
- ループ3の指摘に重大なものが残っていても打ち切る。残った指摘も実録として保存する(著者の加筆修正の材料になる)

## 記録

- 各ループの `作品.md`・`指摘.md`・`判断.md` と、`設定.md` の変更差分をすべて残す(オーケストレータが変更後を `loops/loopN/設定_変更後.md` にコピー)
- `実行記録.md` に日時・モデル・トークン消費を記録する
