書籍の実験で実際に使った部屋の実物コピーです(このREADMEだけが後付け。他のファイルは実験当時のまま無改変)。

- 実行は `/run-loop`(進行役が各役割をサブエージェントとして自動で回す)。手動で1工程ずつ回す方法も含め、[起動フレーズ.md](./起動フレーズ.md) と [手順.md](./手順.md) のとおり
- [設定_初期.md](./設定_初期.md) が開始時の設定、[設定.md](./設定.md) はオーケストレータが書き足す権限を持つ先(収録したのは実験終了時点の状態)
- エディタ指示書の5条(人間への質問を書かない・分岐は申し送りへ)は、書籍第2章で扱う停止事故のあとに改修された版です
- 各周の成果物(loops/)・実行記録・進捗は収録していません
- 応募要項_抽象版.md の「あらすじ100文字以内」は当時の誤情報のまま保存した実物です(顛末は書籍第7章)
