# 応募要項(抽象版)

あなたが書くのは、あるSF系の文学コンテストに応募する短編小説です。

- 課題: **理系的発想力を存分に発揮して、読む人の心を刺激する物語**を書くこと
- 分量: **10,000文字以内**(下限なし。短くても構わない)
- 提出物: **作品本文・タイトル・100文字以内のあらすじ**の3点
- 目標: このコンテストで**最優秀賞(最高評価)を取る**こと

## 禁止・注意事項

- 実在の作家名・作品名に言及しない。特定の作家や作品の文体・内容を模倣しない
- 既存の作品の流用・翻案をしない。完全なオリジナル作品とする
- 差別的・暴力的・性的・誹謗中傷的な表現を含めない
